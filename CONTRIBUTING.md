# Contributing to LIS

Cảm ơn bạn đã quan tâm đến LIS — Learning Intelligence System.

LIS là một dự án đang phát triển nhằm khám phá cách con người, tri thức và AI có thể cùng tham gia vào quá trình kiến tạo tri thức.

## How to Contribute

Bạn có thể đóng góp theo nhiều cách:

- đề xuất ý tưởng mới;
- báo lỗi;
- cải thiện giao diện;
- cải thiện tài liệu;
- phát triển Knowledge Atoms;
- phát triển Knowledge Graph;
- phát triển Grammar Engine;
- phát triển AI Reasoning;
- đề xuất hoặc xây dựng các SBBS mới.

## Development Workflow

1. Fork repository LIS.
2. Clone repository về máy.
3. Tạo một branch mới cho thay đổi của bạn.
4. Thực hiện thay đổi.
5. Kiểm tra ứng dụng hoạt động bình thường.
6. Commit thay đổi với message rõ ràng.
7. Push branch lên GitHub.
8. Tạo Pull Request.

Ví dụ:

```bash
git checkout -b feature/my-feature
